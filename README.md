A token launch radar: it reads a sealed snapshot of every protocol DefiLlama tracks, finds the ones with no token yet, and ranks them by what their launch would be worth — shown in a web dashboard with a board, a detail view for each protocol, and the steps to farm it. 226 protocols ranked; rank 1 is steakhouse-financial at $429,073,965 implied value.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
